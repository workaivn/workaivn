PHASE 8 — SELF-EVOLVING PLATFORM
Phase 8.1 — Self Benchmark Engine
Implement Phase 8.1 - Self Benchmark Engine.

Goal:
WorkAIVN automatically benchmarks every provider/model.

Test:
- JSON tool call
- READ_FILE
- WRITE_FILE
- APPLY_PATCH
- RUN_TERMINAL
- FINAL
- multi-step coding
- read-only analysis

Collect:
- latency
- success rate
- tool accuracy
- JSON validity
- cost
- token usage
- timeout rate

Create:
backend/src/agent/benchmark/

benchmarkRunner.js
modelBenchmark.js
benchmarkStore.js

Output:
MODEL_BENCHMARK_RESULT
MODEL_SCORE
Phase 8.2 — Model Router
Implement Phase 8.2 - Model Router.

Goal:
Automatically choose the best model for each task type.

Route:
- simple read => cheapest fast model
- coding patch => best coding model
- long analysis => long-context model
- local simple task => llama.cpp/Ollama
- hard recovery => cloud model

Use benchmark scores from Phase 8.1.

Never hardcode one default model for everything.
Phase 8.3 — Prompt Optimizer
Implement Phase 8.3 - Prompt Optimizer.

Goal:
WorkAIVN tracks which prompts work best.

Collect:
- prompt template
- model
- task type
- success/fail
- retry count
- quality gate score

Planner should prefer prompt templates with higher success rate.

Create:
promptOptimizer.js
promptExperiment.js
promptTemplateStore.js
Phase 8.4 — Failure Learning
Implement Phase 8.4 - Failure Learning.

Goal:
Every failed run becomes training signal.

Store:
- objective
- failed task
- failed tool
- stderr
- model output
- recovery used
- final result

Planner should avoid repeating known failed strategy.

Create:
failureMemory.js
failurePatternMatcher.js
Phase 8.5 — Auto Regression Generator
Implement Phase 8.5 - Auto Regression Generator.

Goal:
When a bug is fixed, WorkAIVN automatically creates a regression test.

Example:
Bug:
FINAL dispatched as tool

Generated test:
FINAL should be accepted, not executeTool("FINAL")

Create:
regressionGenerator.js
testCaseBuilder.js

Output:
AUTO_REGRESSION_CREATED
Phase 8.6 — Self Refactor Advisor
Implement Phase 8.6 - Self Refactor Advisor.

Goal:
WorkAIVN analyzes its own codebase and suggests refactors.

Detect:
- duplicated planner logic
- large files
- tangled dependencies
- slow paths
- unused helpers
- repeated prompt logic

Do not auto-apply refactor yet.
Only generate advisory report.
Phase 8.7 — Self Patch Mode
Implement Phase 8.7 - Self Patch Mode.

Goal:
WorkAIVN can safely patch its own agent code.

Rules:
- must create plan
- must run tests
- must pass Quality Gate
- must create regression test
- must not modify unrelated files

Self-patching must be explicitly enabled.
Phase 8.8 — Model Cost Governor
Implement Phase 8.8 - Model Cost Governor.

Goal:
Prevent credit burn.

Track:
- per provider cost
- per run cost
- per task cost
- monthly limit
- remaining budget

If low budget:
- prefer local model
- reduce context
- disable expensive retries
- ask user before cloud escalation

Create:
costGovernor.js
budgetPolicy.js
Phase 8.9 — Auto Provider Fallback
Implement Phase 8.9 - Auto Provider Fallback.

Goal:
If one provider fails or hits quota, route to another.

Handle:
- 429 quota
- timeout
- bad JSON
- provider offline
- local server down

Fallback order should be configurable.

Do not lose run state when switching provider.
